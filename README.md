# CalcSpace 🧮

A simple, modern, and responsive calculator website built using HTML, CSS, and JavaScript.

## Features

* Basic arithmetic operations
* Percentage calculations
* Positive and negative number support
* Keyboard input support
* Recent calculations
* Responsive design

## Technologies Used

* HTML
* CSS
* JavaScript

## Project Structure

* `index.html` — Website structure
* `style.css` — Website styling
* `script.js` — Calculator functionality

## Purpose

This project was created to practise web development and learn the fundamentals of HTML, CSS, and JavaScript.
